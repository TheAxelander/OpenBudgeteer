# Security Policy

## Supported Versions

| Version     | Supported          |
|-------------| ------------------ |
| 1.11.1      | :white_check_mark: |
| pre-release | :white_check_mark: |
| < 1.11.1    | :x:                |

The `OpenBudgeteer.API` project and its related Docker Image is experimental and overall not supported.

## Reporting a Vulnerability

For any findings, please draft a [new security advisory](https://github.com/TheAxelander/OpenBudgeteer/security/advisories/new)
